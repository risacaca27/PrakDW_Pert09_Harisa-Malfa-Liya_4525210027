## 🖥️ Hasil Praktikum

### 1. Contoh 1 — SKIN1004's Store (Katalog Produk)

Contoh pertama merupakan website katalog produk skincare dengan nama **SKIN1004's Store**. Website ini menampilkan beberapa produk skincare dari brand SKIN1004 dengan desain bernuansa natural, menggunakan perpaduan warna hijau sage, cream, dan putih.

**Fitur dan komponen:**
- Menampilkan empat produk skincare.
- Menampilkan gambar, nama, ukuran, dan deskripsi produk.
- Menggunakan Bootstrap Grid untuk mengatur susunan kartu produk.
- Menyediakan tombol "Lihat Produk" yang mengarah ke halaman produk resmi.
- Memiliki bagian informasi tentang brand.

**Teknologi:**
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Grid

### 2. Contoh 2 — SKIN1004's Store (Sales Management Dashboard)

Contoh kedua merupakan halaman dashboard pengelolaan data penjualan produk skincare SKIN1004.

Website ini menampilkan ringkasan informasi penjualan serta tabel riwayat transaksi agar data lebih mudah dibaca dan dipahami.

**Fitur dan komponen:**
- Menampilkan total penjualan.
- Menampilkan jumlah produk terjual.
- Menampilkan total transaksi.
- Menampilkan tabel riwayat penjualan produk.
- Menampilkan ID transaksi, nama produk, kategori, jumlah, dan total harga.
- Menampilkan status transaksi seperti Selesai, Diproses, dan Dibatalkan.
- Menyediakan tombol Tambah Penjualan dan Detail.

**Teknologi:**
- HTML5
- CSS3
- Bootstrap 5
